# 及格邊緣：Exam Survival

直接雙擊 `index.html`，在桌面版 Chrome、Edge 或其他現代瀏覽器中開始遊戲。所有遊戲程式和素材都在這個檔案中，不需要安裝套件、啟動伺服器或連接網路。詳細設計見 `規格書.md`。

## 玩法與操作

在五分鐘內完成 20 題單選題，每題 5 分，取得至少 60 分即可及格。自行解題最安全；同學的答案可能有錯，小抄則只包含部分答案。偷看同學時，如果老師面向玩家，或側身朝玩家偷看的方向，會出現警告，可疑值也會快速上升；老師背對或側身朝相反方向時，可疑值則會緩慢上升。老師是否看見偷看不受距離限制，但距離會影響可疑值上升速度。可疑值達到 100 時考試結束。

| 操作 | 功能 |
| --- | --- |
| 滑鼠點選題目、選項 | 選題、填答或修改答案 |
| 1～4 | 對目前標示的題目選 A～D |
| ←／→ 或試卷按鈕 | 翻頁，已填答案會保留 |
| 按住 A／D | 偷看左／右同學的目前試卷，放開回正 |
| 按住 S | 查看抽屜小抄，放開回正 |
| Space | 立即取消按住的視角並平滑回正 |
| 拖曳鏡子下方的箭頭 | 調整觀察後方的角度，拖動越多風險越高 |
| 鏡子箭頭取得焦點後按 ←／→ | 使用鍵盤調整鏡子方向 |
| Esc | 暫停或繼續；失去瀏覽器焦點也會暫停 |
| R | 結算畫面重新開始 |

交卷時若有未答題，需先確認；時間到則自動交卷。方鏡會隨箭頭轉動，並在老師位於玩家後方且進入目前觀察角度時顯示老師；調整完成後不再持續增加可疑值。鏡中對到老師的眼時，老師會加速走近。偷看被老師看見時，放開 A／D 或按 Space 回正可停止高速累積，已累積的可疑值會逐漸下降；老師轉向其他方向時警告也會解除。查看抽屜被老師看見時，會出現驚嘆號與 1.3 秒倒數，並大幅提高可疑值上升倍率；倒數結束前放開 S 或按 Space 回正即可避免被抓。老師不再看見抽屜時警告也會解除。

## 原始需求完成度

- **考試核心：已實作。** 20 題、四頁、每頁五題、答案保留與修改、選題、計時、未完成確認、自動交卷及評分。
- **第一人稱教室：已實作。** Canvas 繪製教室、前方同學、老師與桌椅；左右及抽屜視角有平滑轉場，試卷置於桌面。
- **偷看與小抄：已實作。** 兩位同學使用相同題庫，獨立答題與翻頁；每局預先決定答案，未作答不顯示；小抄隨機提供九題正確答案。
- **老師及風險：已實作。** 老師移動、停留及警覺靠近，正面、側面身體與背面會反映其朝向；老師看見左右偷看時會顯示驚嘆號並加快可疑值累積，查看抽屜則依距離和視野顯示驚嘆號倒數。鏡中對眼會觸發加速靠近。偷看、看小抄、調整鏡子及快速切換視角增加可疑值，停止後逐漸降低，距離會影響增加倍率。
- **鏡子：已實作。** 滑鼠拖曳鏡子下方的方向箭頭會旋轉鏡框與鏡面；鏡面以玩家、老師的相對位置及角度決定是否顯示老師。
- **介面與結局：已實作。** HUD、提示、暫停、勝利、作弊被抓、可疑值達上限、不及格與重新開始。
- **音效：未實作。** 以畫面提示提供警示。
- **GitHub Pages：已按靜態網站結構準備，但尚未實際部署驗證。**

## 驗證方式與限制

以 Chrome 無頭模式直接開啟本機 `file://` 頁面，檢查開始、滑鼠及鍵盤作答、翻頁保留、兩側試卷、小抄、同學作答進度、鏡子滑鼠拖曳及視野變化、老師視線與距離風險、可疑值回落、失焦暫停、交卷確認、60 分勝利、三種失敗及時間到交卷。更新後另測試 A／D 搭配老師正面、左右側面及背面的目擊判定、回正後警告解除與可疑值下降、可疑值上限、抽屜警告及鏡框旋轉。部分結局、老師位置與時間到測試透過設定遊戲狀態觸發，並非逐次等待完整五分鐘；也尚未在實際 GitHub Pages 網址或所有瀏覽器測試。

場景與鏡面採簡化的 2D／2.5D 畫法，不是完整 3D 透視或物理反射。遊戲主要針對桌面鍵盤與滑鼠設計。難度參數集中在 `index.html` 的 `CONFIG`，可以修改時間、老師速度、視野、可疑值變化及同學正確率。

## GitHub Pages 部署

1. 在 GitHub 建立儲存庫，將 `index.html` 上傳到儲存庫根目錄並提交。
2. 開啟儲存庫的 **Settings → Pages**。
3. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**。
4. 選擇放有檔案的分支（例如 `main`）及 **/(root)**，按 **Save**。
5. 等待部署完成，在 Pages 設定頁開啟產生的網址。後續更新 `index.html` 並推送至該分支即可重新發布。

詳細設定可參考 [GitHub Pages 官方說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。
